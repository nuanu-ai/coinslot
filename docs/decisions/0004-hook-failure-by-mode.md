# 0004. Молчание хука цены: политика отказа зависит от режима выдачи

Дата: 2026-08-26
Статус: proposed (принимает Дмитрий)
Уточняет: пункт 3 ADR-0002.

## Контекст

ADR-0002 задал молчанию quote-hook единую политику открытого провала:
продажа продолжается по снапшоту. Чистое ревью мерчантской документации
(2026-08-26) нашло следствие, которое мы не увидели: в асинхронном режиме
деньги исполняются в момент покупки, то есть открытый провал производит
продажи при неизвестном наличии — ровно те заказы «деньги взяты, товара
нет», для которых механика возврата ещё не выбрана. Это противоречит
нашему же принципу «любое сомнение трактуется против списания».

## Решение

Открытый провал хука (продажа по снапшоту) действует только в режимах,
где между снапшотом и деньгами стоит живой ответ мерчанта: в синхронном
(выдача до исполнения платежа) и в режиме с подтверждением (подтверждение
до платежа). В асинхронном режиме молчание хука — закрытый провал:
покупка не начинается.

## Последствия

- Асинхронные товары с хуком теряют продажи на время недоступности хука.
  Это осознанная цена: потерянная продажа дешевле долга перед покупателем
  при невыбранной механике возврата.
- Правило одной строкой для мерчанта: «пока ваш ответ стоит до денег,
  ваше молчание бесплатно для покупателя; когда деньги идут сразу — ваше
  молчание останавливает продажу».
- Отклонено: единый открытый провал для всех режимов (порождает
  refund_due), единый закрытый (убивает синхронные продажи, которые можно
  честно провести по снапшоту и живому отказу выдачи).
