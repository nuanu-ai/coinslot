# 0001. Пилот экспонируется в x402 Bazaar через CDP facilitator

Дата: 2026-08-25
Статус: proposed (принимается после успешного первого settle и подтверждения
Дмитрия)

## Контекст

Исследование (`docs/research/02-agentic-storefronts.md`) показало: единой
глобальной витрины для агентов нет; единственный живой end-to-end цикл
«агент нашёл → агент заплатил» — x402 Bazaar (+ Agentic.Market поверх него);
mainstream-ассистенты живут на карточных рельсах с фрагментированными
каталогами. Услуги пилотного мерчанта Freeland — API-shaped, то есть
соответствуют и схеме Bazaar, и текущему профилю спроса. Спайк
(`04-spike-bazaar-listing.md`) подтвердил: листинг автоматизируем полностью,
официальная валидация пройдена (x402 v2, 25/25).

## Решение

Пилот экспонирует каталог через CDP facilitator (settle → автокаталогизация в
Bazaar; попутно — видимость в Agentic.Market, AWS AgentCore, Cloudflare/Vercel
агентах). Витрина генерируется из конфига мультимерчантно; `payTo` —
per-мерчант, деньги идут напрямую мерчанту (non-custodial). Фасилитатор
держим за интерфейсом как заменяемую роль (совместимый B402 существует).

## Последствия

- Плюсы: вход за часы, $0 до 1000 settle/мес, единственный канал с реальным
  машинным спросом сегодня; формат метаданных уже мультивендорный.
- Платим: зависимость от CDP уровня «хостинг» (OFAC/KYT-скрининг, аккаунт);
  обязанность держать листинги живыми (30-дневный пульс, health-probes);
  спрос на не-API товары в канале пока эмбрионален — метрики пилота ставим
  реалистично (единицы-десятки вызовов/мес — уже успех).
- Отклонено: мультиканальный адаптер (фиды ассистентов, MCP-каталоги, UCP) на
  этапе пилота — преждевременно; вернёмся после первых органических продаж.
