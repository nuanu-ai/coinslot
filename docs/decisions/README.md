# Architecture Decision Records

Здесь фиксируются принятые решения. Одно решение — один файл `NNNN-slug.md`.

Шаблон:

```markdown
# NNNN. Название решения

Дата: YYYY-MM-DD
Статус: accepted | superseded by NNNN

## Контекст
Почему вопрос встал, какие были ограничения.

## Решение
Что решили, одним-двумя абзацами.

## Последствия
Что это даёт и чем придётся платить. Какие альтернативы отклонили и почему.
```
