# Открытые вопросы

Стартовый список для discovery. Вычёркиваем по мере ответов; ответы, ставшие
решениями, уходят в `docs/decisions/`.

## Продукт
- [x] Что такое Coinslot: какую проблему решает и для кого? → `01-hypothesis.md`
- [ ] Каков минимальный полезный результат (MVP) и что сознательно откладываем?
- [x] Есть ли аналоги/конкуренты, от которых отталкиваемся? →
      `02-agentic-storefronts.md` (ниша пуста; ближайшие: Stripe syndication /
      PayPal Store Sync — фиат; Bitrefill/Travala — прецеденты мерчантов в x402)
- [ ] Механика адреса доставки для физических товаров — когда дойдём до них
- [ ] Возвраты: изучить практику работающих продавцов в агентных платежах,
      взять готовый паттерн → `10-design-backlog.md`
- [ ] Остатки и гонка за последний экземпляр: нужен дизайн без журнала
      остатков на стороне Coinslot → `10-design-backlog.md`
- [ ] Споры: минимальная роль Coinslot, максимум у мерчанта →
      `10-design-backlog.md`
- [ ] Процедура снятия карточек из каталогов — задокументировать →
      `10-design-backlog.md`
- [ ] Видимость на пустом рынке: имитация покупок недопустима — нужен ли
      честный способ поддерживать видимость? → `10-design-backlog.md`

## Ограничения
- [ ] Платформа: web / mobile / desktop / CLI / сервис без UI?
- [ ] Один пользователь или многопользовательская система? Нужны ли аккаунты?
- [ ] Где живут данные: локально, своё хранилище, внешние API?
- [ ] Ограничения по бюджету, срокам, хостингу?

## Стек и архитектура

- [ ] Какие интеграции обязательны с первого дня?
