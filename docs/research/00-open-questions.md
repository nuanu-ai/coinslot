- [ ] Сбои и обязательства нашей стороны: что обещаем мерчанту при

- [ ] Юр/налоговый контур сделки: кто продавец, какой документ получает

- [ ] Канал общения мерчанта с покупателем в споре: покупатель — программа,
      человек с поддержкой не переписывается — кому мерчант отвечает?
- [ ] Чьи контакты приходят в параметрах покупки (почта агента или
      человека за ним): кому мерчант открывает кабинет и шлёт уведомления
      (гейт №2, владелец)
- [ ] Ранжирование и ценовая конкуренция в каталогах: с кем и по чему
      сравнивает агент (гейт №2)
- [ ] Юр-идентичность в портале: кто «мы» для мерчанта, который отдаёт
      ключ от API (гейт №2; связка с юр/налоговым контуром выше)
- [ ] Молчащее списание никто не переспрашивает: у клиента фасилитатора есть
      verify, settle и список поддерживаемого — способа спросить «что стало с
      этим списанием» нет, а повторный settle запрещает машина. Заказ остаётся
      в `outcome_unknown`, пока платёжный слой не заговорит сам, и разобрать
      такой случай можно только руками — по словам фасилитатора, записанным в
      заказе. Подробности — в комментарии к `#settle` в
      `apps/gateway/src/app/runner.ts`.

## Техрешение этапа 1 (закрываем по ходу)
- [x] Имя и форма заголовка ключа → зафиксированы в contracts
      (`MERCHANT_KEY_HEADER`, `merchantKeyHeaderValue`, `merchantKeyFrom` в
      `packages/contracts/src/api.ts`); гейтвей и SDK импортируют один
      источник, drift ловит тест api.test.ts
- [ ] Сборка публикуемых пакетов: без неё `bin` SDK не запускается (Node не
      переписывает `.ts`→`.js`), поэтому `npx coinslot verify` из портала
      сегодня невыполним, а verify живёт как экспорт `runVerify`/`checkCard`.
      Приезжает с changesets (ADR-0003 §8) — этап 2
- [ ] Тестовый путь для идемпотентности verify: нет маршрута, поднимающего
      заказ по своей карточке для теста, и нет способа сделать `Order.test`
      истинным без живого платежа — verify v0 честно останавливается на этой
      половине
- [ ] Параллелизм подписки воркера (имя параметра и умолчание) — портал сам
      держит их нерешёнными
