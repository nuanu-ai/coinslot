# Куда экспонировать товары и услуги для агентов — состояние на 2026-08-25

Ответ на первый вопрос гипотезы ([01-hypothesis.md](01-hypothesis.md)).
Метод: три параллельных исследовательских потока (x402-нативные каталоги;
агентная коммерция больших платформ; каналы обнаружения агентами), веб-источники
с датами + прямой краул discovery-API Bazaar 2026-08-25.

## Короткий ответ

Единой глобальной витрины нет. Существуют три разных мира, и только один из них
x402-нативный:

1. **Mainstream-ассистенты** (Google, Microsoft, Perplexity, Amazon, OpenAI) —
   живой покупательский трафик, но фрагментированные каталоги на карточных
   рельсах; x402 нигде не в проде.
2. **x402-нативные витрины** (Bazaar, Agentic.Market) — механически живые,
   открытые, вход self-serve за часы; но это витрина API-микроплатежей почти
   без покупателей.
3. **Собственный сайт + структурированные фиды** — где сегодня реальная
   конверсия («нашёл в AI — купил на сайте»).

Ниша «классический web2-мерчант → x402» не занята никем. Единственные близкие
прецеденты — Bitrefill и Travala.

## 1. Mainstream: витрины ассистентов (карточные рельсы)

- **OpenAI**: Instant Checkout (сент. 2025, Stripe/ACP) **свёрнут в марте 2026**
  — менее ~30 живых Shopify-мерчантов за полгода; конверсия в чате ~3× хуже
  сайта. Пивот к «discover in AI, buy on site»: продуктовые фиды
  (chatgpt.com/merchants) + ChatGPT Apps (Walmart, Target). [CNBC 2026-03-24]
- **Google**: реально живой слой — **UCP** (открытый стандарт с Shopify/Etsy/
  Walmart; чекаут у Nike, Sephora, Target) + Universal Cart (I/O 2026). AP2
  остаётся протоколом мандатов; его **x402-extension** — крипто-нога (Coinbase,
  EF, MetaMask). UCP принял и Microsoft → главный кандидат на конвергенцию.
- **Microsoft**: Copilot Checkout (янв. 2026, PayPal) — 500k+ мерчантов.
- **Perplexity**: бесплатная Merchant Program (фид в формате Google Shopping),
  Instant Buy с PayPal/Venmo, мерчант остаётся merchant-of-record, 0% fee.
- **Amazon**: Buy for Me — крупнейший объём, мерчантов скрейпят и включают
  **без согласия** (opt-out по email), бренды протестуют.
- **Агрегаторы уже продают модель «один каталог → много ассистентов»**:
  Stripe Agentic Commerce Suite (дек. 2025, syndication из Dashboard) и PayPal
  Store Sync (питает Perplexity и Copilot). Это подтверждение модели шлюза —
  но всё на фиате, без x402.
- **Карточные сети легитимизируют агентов**: Visa Intelligent Commerce — живые
  транзакции в ЕС с июля 2026 (Trusted Agent Protocol с Cloudflare); Mastercard
  Agent Pay — все картхолдеры США с ноября 2025, «Agent Pay for Machines»
  (июнь 2026) явно комбинирует x402 с сетью MC.

## 2. x402-нативные витрины

**Механика листинга (Bazaar, проверено по докам CDP):** платежи через CDP
facilitator + discovery extension в middleware; метаданные: описание ≤500
символов, JSON Schema входов/выходов, цена, сети. Первый успешный платный вызов
→ автокаталогизация; ранжирование каждые 6 ч; **делистинг после 30 дней без
вызовов**. Только HTTP API — модели товара/SKU/фулфилмента в схеме нет.
Facilitator: Base, Polygon, Arbitrum, World, Solana; 1000 сеттлментов/мес
бесплатно, дальше $0.001. Binance **B402 Bazaar** — совместимый клон формата →
метаданные становятся де-факто мультивендорным стандартом.

**Замер каталога (прямой краул 2026-08-25):**

- 15 245 ресурсов на 1 630 доменах; **суммарно ~306K платных вызовов за 30
  дней; медианный листинг — 1 вызов/мес**; топ-100 забирают 72% трафика.
- Топ продавца на x402scan: ~$3.1K/30д (реселлер API). Никто не зарабатывает
  всерьёз.
- Заголовочные цифры протокола (75M txn / $24M за 30д на x402.org) — в
  основном другие фасилитаторы и **~50% gamified-активность** (Artemis via
  CoinDesk 2026-03-11); оценка реальной коммерции ~$28K/день.
- **Не-API товары эмбриональны, но прецеденты есть**: Bitrefill (gift cards,
  eSIM, mobile top-ups, 180+ стран — ~100 вызовов/мес), palmyr.ai (prepaid
  Visa $5–1000), Resy-бронирования, Travala (отели, MCP+x402 с 2026-06-05),
  StableMerch (футболки). Физического фулфилмента практически ноль.

**Agentic.Market** (Coinbase, апр. 2026): витрина для людей и агентов поверх
x402 — 2 375 сервисов, программный доступ `GET /v1/services`.

**Институции**: x402 Foundation оперативна с 2026-04-02 под Linux Foundation,
~40 членов (Visa, MC, Amex, Google, Microsoft, AWS, Cloudflare, Shopify,
Stripe, Circle…). Рельсы легитимизированы; публичный роадмап пуст
(«update coming soon»). Cloudflare: Monetization Gateway (x402) — waitlist;
монетизация без дискавери.

## 3. Каналы обнаружения: что реально работает

- **Крупнейший реальный поток покупателей — assistant-mediated discovery
  собственного каталога**: фиды + schema.org + Shopify Catalog MCP/UCP.
  Adobe Q1 2026: AI-трафик к ритейлерам США +393% YoY, конверсия на 42% лучше
  обычного. Модель: агент находит — человек подтверждает покупку на сайте.
- **Единственный живой цикл «агент сам нашёл и сам заплатил» — x402 Bazaar**:
  нативно потребляется агентами AWS Bedrock AgentCore, Cloudflare, Vercel
  (`x402-mcp`). Объёмы малы (см. выше), но цикл работает end-to-end.
- **Дёшево и полезно**: MCP-сервер в каталоге коннекторов Anthropic
  (курируемый, живые пользователи Claude; Anthropic строит commerce-UX).
- **Шум (сегодня не тратить время)**: llms.txt (краулеры не читают), Fetch.ai
  Agentverse (2.7M «агентов» без коммерции), MIT NANDA (академический),
  agents.txt, NLWeb (заглох), Virtuals ACP (субсидируемый крипто-контур),
  ERC-8004 (170K+ регистраций, но 85–97% без валидного registration file;
  reputation-слой не работает — arXiv:2606.26028).

## Выводы для Coinslot

1. Гипотеза «есть куда экспонироваться» **подтверждена наполовину**: витрина
   есть (x402-нативная, открытая, вход за часы, формат мультивендорный), но
   покупателей на ней мало. В mainstream витрины нет — там фрагментация,
   карточные рельсы и агрегаторы без x402.
2. **Ниша Coinslot реально пуста**: карточные игроки агрегируют дистрибуцию без
   x402; у x402 витрина без мерчантов. Никто не строит «ворота» для web2-
   мерчанта в x402.
3. Трезвая оговорка: ниша может быть пуста и потому, что платёжеспособного
   агентского спроса на не-API-товары пока нет. Это главный риск гипотезы.
4. **Для пилота с Freeland риск минимален**: его услуги (eSIM, номера, VPN,
   AI-чат) — API-shaped, то есть ровно тот тип товара, который соответствует
   схеме Bazaar и сегодняшнему спросу. Прямой прецедент — Bitrefill (продаёт
   eSIM/top-ups через x402 уже сейчас).
5. Практический путь экспонирования пилота: CDP facilitator + discovery
   extension → Bazaar (авто) → виден в Agentic.Market, AWS AgentCore, Cloudflare
   и Vercel-агентах; совместимый blob → B402. Плюс дешёвый второй канал — MCP-
   сервер (x402-mcp) с подачей в каталог Anthropic.
