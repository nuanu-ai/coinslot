# Freeland — пилотный мерчант

Источник: локальный репозиторий `~/Dev/freeland` (CLAUDE.md, AGENTS.md,
`docs/current-architecture.md`, `skills/freeland/SKILL.md`). Прод:
https://mf0.store (бренд freeland.land). Дата: 2026-08-25.

## Что это

«Agent-first privacy platform»: кошелёк + цифровые privacy-сервисы под одним
пользовательским аккаунтом. Стек: pnpm/turbo монорепо, Node API + worker (PM2),
React PWA + Telegram Mini App, Supabase (auth + DB).

## Ключевые факты для Coinslot

1. **Freeland уже agent-first по замыслу** — есть `skills/freeland/SKILL.md`,
   агентский гайд по API (`https://mf0.store/api`). Но:
2. **Машинной аутентификации нет — сознательно.** Customer API keys retired по
   соображениям безопасности; доступ только через session JWT пользователя.
   Агент сегодня может действовать только «внутри» аккаунта человека.
   → x402 здесь не просто «ещё один способ оплаты»: pay-per-request может
   **заменить** аккаунтную аутентификацию для разовых покупок (оплата = право
   на ресурс), не нарушая запрет на долгоживущие ключи.
3. **Платёжная оркестрация провайдер-нейтральна**: контракт
   `capabilities → options (signed quote) → checkouts → status`, fail-closed,
   идемпотентность, immutable pricing snapshot. Архитектурно есть два пути:
   x402 как новый payment method внутри этого контракта, либо Coinslot как
   внешняя витрина поверх выделенных SKU.
4. **Кандидаты на первую x402-продажу** (не требуют аккаунта/KYC):
   - VPN: оплата → выдача WireGuard-конфига (чистая разовая сделка);
   - eSIM: оплата → QR/LPA-профиль;
   - виртуальный номер: оплата → номер + чтение OTP (метериться может
     per-message);
   - Mr. Freeman / AI-прокси: классический per-request микроплатёж.
   Карты — худший кандидат (KYC, комплаенс, санкционные риски).
